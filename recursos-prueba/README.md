# Recursos de prueba — Tekaym Online

Esta carpeta es exclusivamente para guardar recursos experimentales y avances en desarrollo. **Nada aquí se integra ni se carga automáticamente en el juego.**

## Organización prevista

- `modelos-3d/`: modelos y pruebas de personajes, zombis y objetos.
- `animaciones/`: pruebas de animación y movimientos.
- `texturas-y-materiales/`: texturas, materiales y variantes visuales.
- `prototipos/`: archivos experimentales y versiones preliminares.

Los recursos terminados solo se incorporarán a las carpetas definitivas del juego después de revisarlos. Este espacio pertenece únicamente a Tekaym Online y no debe mezclarse con DarkPixel Online.

GitHub no conserva carpetas vacías; por eso este README hace que la carpeta aparezca desde ahora.
